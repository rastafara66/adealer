Navy & gold theme for the Odoo backend

Фірмова navy & gold тема для бекенду Odoo

Version 18.0.1.2.3 · Odoo 18 · pure CSS, no SCSS rebuild, no JS

Odoo 18 edition. Not all features of newer versions are available here — the full feature set is in the version for Odoo 19.
Версія для Odoo 18. Тут доступні не всі функції, що є в новіших версіях, — повний набір у версії для Odoo 19.

What it changes / Що змінює

A calm, consistent palette across the whole backend instead of the default purple. Pure CSS: nothing to recompile, nothing to unbreak later. — Спокійна послідовна палітра замість типового фіолетового, чистим CSS: нічого не перекомпільовується і нічого потім не ламається.

Interface

  • Top bar — navy gradient with a gold line; menu items turn gold on hover (all states: hover / focus / active)
  • Buttons — primary navy with gold text on hover, secondary light with a blue outline
  • Lists — light-blue header and totals, row highlight
  • Tabs, checkboxes, switches, breadcrumbs and the pager — one palette

Інтерфейс

  • Верхня панель — темно-синій градієнт із золотою лінією; пункти меню при наведенні золоті (всі стани)
  • Кнопки — primary navy із золотим текстом при наведенні, secondary світлі з синім контуром
  • Списки — світло-сині шапка та підсумки, підсвітка рядка
  • Вкладки, чекбокси, перемикачі, breadcrumbs і пейджер — в одній палітрі

Installation / Встановлення

Pure CSS — no SCSS recompilation, no JavaScript. Installs and uninstalls on its own (depends only on web). Designed to match the 3A-dealer app, but works with any Odoo.

Чистий CSS, без перекомпіляції SCSS і без JS. Ставиться й видаляється незалежно (залежить лише від web). Пасує до додатка 3A-dealer, але працює з будь-яким Odoo.
