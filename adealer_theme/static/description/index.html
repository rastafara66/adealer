Navy & gold theme for the Odoo backend

A calm palette instead of the default purple · pure CSS

Version 19.0.1.2.3 · Odoo 19 · pure CSS, no SCSS rebuild, no JS

What it changes

A calm, consistent palette across the whole backend instead of the default purple. Pure CSS: nothing to recompile, nothing to unbreak later.

Interface

  • Top bar — navy gradient with a gold line; menu items turn gold on hover (all states: hover / focus / active)
  • Buttons — primary navy with gold text on hover, secondary light with a blue outline
  • Lists — light-blue header and totals, row highlight
  • Tabs, checkboxes, switches, breadcrumbs and the pager — one palette

Menu sidebar

  • The current app's menu tree on the left, collapsible, in any Odoo app
  • Where the 3A-dealer module draws its own sidebar, the theme stands down — nobody ends up with two

Installation

Pure CSS — no SCSS recompilation, no JavaScript. Installs and uninstalls on its own (depends only on web). Designed to match the 3A-dealer app, but works with any Odoo.

Тема navy & gold для бекенду Odoo

Спокійна палітра замість типового фіолетового · чистий CSS

Odoo 19 · чистий CSS, без перекомпіляції SCSS і без JS

Що змінює

Спокійна послідовна палітра по всьому бекенду замість типового фіолетового. Чистий CSS: нічого не перекомпільовується і нічого потім не ламається.

Інтерфейс

  • Верхня панель — темно-синій градієнт із золотою лінією; пункти меню при наведенні золоті (у всіх станах)
  • Кнопки — основні темно-сині із золотим текстом при наведенні, другорядні світлі з синім контуром
  • Списки — світло-сині шапка й підсумки, підсвітка рядка
  • Вкладки, прапорці, перемикачі, «хлібні крихти» й гортання сторінок — в одній палітрі

Бічне меню

  • Дерево меню поточного застосунку зліва, згортається, у будь-якому застосунку Odoo
  • Де модуль 3A-dealer малює власне бічне меню, тема поступається — двох меню не буде

Встановлення

Чистий CSS — без перекомпіляції SCSS і без JavaScript. Ставиться й видаляється незалежно (залежить лише від web). Пасує до додатка 3A-dealer, але працює з будь-якою Odoo.

Підтримка

Питання, помилки, побажання: adealer@aktiv.in.ua. Відповідаємо українською або англійською.

Якщо щось працює не так, напишіть версію Odoo і що ви очікували побачити, — це найкоротший шлях до виправлення.
