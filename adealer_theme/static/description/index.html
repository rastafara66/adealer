3A-dealer Theme

Фірмова navy & gold тема для бекенду Odoo

Navy & gold backend theme for Odoo

Що змінює

  • Верхня панель: темно-синій градієнт із золотою лінією; пункти меню при наведенні — золоті (всі стани: hover / focus / active).
  • Кнопки: primary — navy із золотим текстом при наведенні; secondary — світлі з синім контуром.
  • Списки: світло-сині шапка та підсумки, підсвітка рядка.
  • Вкладки, чекбокси, перемикачі, breadcrumbs, пейджер — усе в одній палітрі.

Особливості

  • Чистий CSS — без перекомпіляції SCSS, без JS.
  • Встановлюється і видаляється незалежно (залежить лише від web).
  • Пасує до додатку 3A-dealer, але працює з будь-яким Odoo.
