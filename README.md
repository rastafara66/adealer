# 3A-dealer

Вертикальне рішення для автодилерів та СТО на **Odoo 19**: Автосалон ·
Автозапчастини · Авторемонт (СТО), зі звичним для користувачів 1С документообігом.

*Car dealership & service workshop management for Odoo 19.*

## Основні можливості

- Ланцюжок документів як у 1С: Замовлення клієнта → Наряд-замовлення →
  Видаткова / Акт / Рахунок.
- Наряд-замовлення СТО: клієнт, авто (VIN), пробіг, механіки, консультант,
  запчастини й роботи, контроль залишків.
- Картотека автомобілів: VIN, бренд (лого), історія ремонтів, календар ТО.
- Запчастини та аналоги, нормо-години, виробіток механіків.
- Звіти: «Готові звіти» (як у 1С) + інтерактивний pivot Odoo.
- Друковані форми (UA): рахунок, видаткова, повернення, прибуткова,
  довіреність, акт звірки.
- Українська локалізація.

## Встановлення

1. Скопіювати теки `adealer/` (і за бажанням `adealer_theme/`) в каталог
   addons вашого Odoo 19.
2. Оновити список застосунків → встановити **3A-dealer**.

**Залежності Python:** `pandas`, `openpyxl` (для імпорту з Excel).
