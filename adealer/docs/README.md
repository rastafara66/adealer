# Документація модуля 3A-dealer (`adealer`)

Документи по функціональних блоках. Оновлювати при кожній зміні відповідної фічі
(правило: підйом версії + changelog + оновлення цих доків).

| Документ | Про що |
|---|---|
| [dashboard.md](dashboard.md) | Дашборд «Головна» — Автосалон / Автосервіс / Автозапчастини |
| [service-booking.md](service-booking.md) | Попередній запис на обслуговування + дошка по постах |
| [showroom-vehicles.md](showroom-vehicles.md) | Автосалон і автомобілі (`dealer.car`) — обʼєкт vs товар |
| [sales.md](sales.md) | Продажі: Реалізації, продажі авто, лінк авто↔документ |

**Загальна архітектура:** документо-центричний UI у класичному обліковому стилі. Ланцюг
сервісу: Заявка → Замовлення клієнта → Наряд-замовлення → Видаткова (товари) / Акт (послуги).
Модуль generic; специфіка конкретного розгортання (імпорт даних зі старих систем) —
в окремих надбудовах поза цим репозиторієм.
