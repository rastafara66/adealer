# Продажі

Розділ **Продажі**: замовлення клієнтів, наряди, Реалізації (Видаткові) і окремо продажі авто.

## Документи

- **Замовлення клієнтів** — `sale.order` (подано як «замовлення клієнта», не «комерційна пропозиція»).
- **Наряд-замовлення** — `repair.order` (журнал у стилі 1С).
- **Реалізації** — `account.move` типу `out_invoice` (Видаткова). 1С-журнал: Дата, Номер,
  Клієнт, 1С-ref, Сума, Статус, Оплата.

Меню: **Продажі → Замовлення клієнтів / Наряд-замовлення / Реалізації / Продажі авто**.

## Продажі авто (окремо від решти реалізацій)

У 1С/Odoo продаж авто — це та сама Реалізація, лише в рядку стоїть авто. Тому авто-продажі
позначаються **за обʼєктом** (VIN у довіднику Автомобілі), а не за назвою:

- **`account.move.is_vehicle_sale`** (stored, computed) — True, якщо в документі є продане авто.
- **`account.move.dealer_car_ids`** — які машини продані в цій Реалізації
  (`action_view_dealer_cars` — кнопка «продані авто»).
- **`dealer.car.sale_move_id`** — зворотний лінк: документ продажу цього авто.

Способи побачити авто-продажі:
1. Меню **Продажі → Продажі авто** — лише Реалізації з авто-рядком.
2. У списку **Реалізації** — фільтр **«Продаж авто»** (`is_vehicle_sale`) + колонка «Авто».
3. Зі **Склад авто** → форма авто → кнопка «Документ продажу».
4. Дашборд **Автосалон** — зведення продажів авто.

## Звʼязок обʼєкт ↔ документ

Проставляється при імпорті авто (`import_dealer_cars.py` пише `sale_move_id`) або лінкером
за VIN. `is_vehicle_sale` перераховується автоматично від `dealer_car_ids`.

## Код

`views/journals.xml` (список Реалізацій + фільтр/колонка), `views/views.xml` (дії/меню),
`models/dealer_car.py` (розширення `account.move`: `is_vehicle_sale`, `dealer_car_ids`).
