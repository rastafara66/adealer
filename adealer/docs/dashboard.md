# Дашборд «Головна»

Стартова сторінка застосунку — зведення по трьох напрямках бізнесу.

## Що це

Перший пункт меню (`Головна`, sequence 0), відкривається за замовчуванням після входу.
OWL client-action `adealer_dashboard` з перемикачем **типу дашборду** і **вибором періоду**.

Три типи (вкладки):
- **Автосалон (showroom)** — продажі авто.
- **Автосервіс (service)** — наряди, виручка СТО, календар найближчих ремонтів.
- **Автозапчастини (parts)** — склад, видача/продаж запчастин.

Кожен показує: **KPI-плитки** + **стовпчиковий графік по місяцях** (inline SVG, без зовнішніх
бібліотек) + **список** (нещодавні продажі / найближчі ремонти / топ складу).

## Модель даних

- `adealer.dashboard` (AbstractModel, без таблиці) — метод `get_data(dash_type, date_from, date_to)`,
  який фронтенд викликає через `call_kw`. Повертає `{currency, kpis, series, list}`.

Джерела по типах:
| Тип | Джерело | Ділова дата |
|---|---|---|
| Автосалон | `dealer.car` (продані авто, статус sold/delivered) | `sale_date` |
| Автосервіс | `repair.order` | `schedule_date` (не `create_date` — то дата імпорту) |
| Автозапчастини | `repair.line` (не-послуги) + `product.product` (склад) | `repair_id.schedule_date` |

## Де знайти / стартова сторінка

- Меню: **Головна** (перший пункт, без підменю).
- Стартова за замовчуванням: `post_init_hook` + міграція `19.0.1.4.0` виставляють дашборд
  home-дією внутрішнім користувачам без своєї стартової. Змінити: Налаштування → Home page.

## Нотатки

- Автосалон рахує продажі **за реальним обʼєктом** `dealer.car` (VIN), а не за назвою рядка —
  див. [showroom-vehicles.md](showroom-vehicles.md).
- Автосервіс/Автозапчастини групують по `schedule_date`, бо `create_date` у мігрованих даних =
  час імпорту (усі в одному місяці).
- Код: `models/dashboard.py`, `static/src/js/dashboard/`, `views/dashboard.xml`.
