# Автосалон і автомобілі (`dealer.car`)

Облік автомобілів як **унікальних обʼєктів** (не знеособлений товар).

## Обʼєкт vs товар — головний принцип

Авто — товар економічно, але НЕ технічно: кожна машина унікальна (VIN, двигун, колір,
опції), має індивідуальну ціну й життєвий цикл. Тому:

- **`dealer.car`** = фізична машина (ідентичність і доля).
- **`product` (товар)** = як цю машину провести в обліку (рядок Реалізації: рахунок доходу,
  ПДВ, сума). Звʼязок — по **VIN**.

Розлоге пояснення: `Projects/adealer/Товар і автомобіль в Odoo.md`.

## Модель `dealer.car`

Ключові поля: `vin`, `model_id` (→ `fleet.vehicle.model`, необовʼязкове),
`model_name_1c` (текст моделі, коли модель не зіставлена), `color_id`, `model_year`, `engine_volume`,
`transmission`, `is_trade_in`, `purchase_price`, `sale_price`, `total_price`,
`supplier_id`, `partner_id` (покупець), `sale_order_id`, `sale_date`,
`sale_move_id` (→ документ продажу), `vin_1c` (ключ дедуплікації),
`fleet_vehicle_id` (сервісне авто після передачі).

**Статуси:** `ordered → in_transit → in_stock → reserved → sold → delivered`.

## Життєвий цикл: склад → сервіс

1. Куплена на продаж → `dealer.car` (склад/товар-обʼєкт).
2. Продана й видана → з `dealer.car` народжується **`fleet.vehicle`** (`fleet_vehicle_id`).
3. Гарантійне ТО → обслуговується у `fleet.vehicle` (історія, наряди).

Тобто клієнтські/продані авто на сервісі — це `fleet.vehicle`, а склад дилера — `dealer.car`.

## Де знайти

- Меню **Автосалон → Склад авто** — список/форма `dealer.car`.
- Форма, вкладка **Продаж**: дата, сума, покупець, **документ продажу** + smart-кнопка
  «Документ продажу» (→ сама Реалізація).
- Дашборд **Головна → Автосалон** рахує продані авто за `sale_date`.

## Продаж — за VIN-обʼєктом

Продаж авто визначається **за реальним обʼєктом**: рядок Реалізації, у назві якого
17-значний VIN, що **існує** у довіднику автомобілів. Послуги/запчастини (без VIN) як
продаж авто НЕ рахуються. Дані продажу (дата/сума/покупець/документ) — з Реалізації;
`vin_1c` — ключ ідемпотентності при завантаженні зі зовнішнього джерела.

## Фотогалерея (з 19.0.1.8.0)

У картці авто є **головне фото** (`image_1920`, аватар у формі) і **галерея додаткових
знімків** — модель `dealer.car.image` (`image.mixin`, поле `sequence`), вкладка «Photos».
`image_count` рахує всі фото. Це базове сховище знімків для вітрини салону і для експорту
оголошень (напр. конектор AUTO.RIA бере фото саме звідси — оголошення без фото не публікується).
