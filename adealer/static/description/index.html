3A-dealer

Car dealership • Auto parts • Service workshop

Автосалон • Автозапчастини • Авторемонт (СТО)

Interface available in English and Ukrainian • Інтерфейс англійською та українською

What's inside

  • Document chain: Sale Order → Repair Order → Delivery note / Act / Invoice — each document is created "on the basis of" the previous one, keeping the links.
  • Repair orders (workshop): customer, vehicle (VIN), mileage, mechanics, service advisor, parts & labour, stock control, parts issue from the warehouse.
  • Customer vehicles: card file with VIN, brand (logo), repair history; service booking calendar and maintenance reminders.
  • Showroom stock: cars as inventory with statuses (ordered / in transit / in stock / reserved / sold), trims, colors, options, trade-in.
  • Parts & analogs: interchangeable-part groups, standard hours, mechanic output.
  • Reports in two styles: "Ready reports" (parameter header → Generate → statement) and the interactive Odoo pivot: Sales, Gross profit, Receivables with per-document detail, ABC analysis, Maintenance reminders, Inactive customers, Stock turnover and more.
  • Printable forms: invoice for payment, delivery note, return note, goods-receipt note, power of attorney, reconciliation act.
  • Document journals: Date | Number | Customer | Vehicle | Amount | Status.
  • Branded theme + side menu (navy/gold) — toggled in Settings, on by default.
  • Excel import: a wizard to load partners when migrating from a legacy system.
  • Bundled database of ~60 car-brand logos, auto-assigned by brand name.

Who it's for

Car dealers, showrooms and service workshops of any brand that want a familiar, document-centric workflow in Odoo.

Що всередині

  • Ланцюжок документів: Замовлення клієнта → Наряд-замовлення → Видаткова / Акт / Рахунок — кожен документ створюється «на підставі» попереднього зі збереженням звʼязків.
  • Наряд-замовлення (СТО): клієнт, автомобіль (VIN), пробіг, механіки, сервісний консультант, запчастини й роботи, контроль залишків, видача ЗЧ зі складу.
  • Автомобілі клієнтів: картотека з VIN, брендом (лого), історією ремонтів; календар записів на обслуговування та нагадування про ТО.
  • Склад автосалону: авто як товарний запас зі статусами (замовлено / в дорозі / на складі / резерв / продано), комплектації, кольори, опції, trade-in.
  • Запчастини та аналоги: групи взаємозамінних запчастин, нормо-години, виробіток механіків.
  • Звіти у двох стилях: «Готові звіти» (шапка параметрів → Сформувати → відомість) та «Конструктор» (інтерактивний pivot Odoo): Продажі, Валовий прибуток, Взаєморозрахунки з деталізацією по документах, ABC-аналіз, Нагадування про ТО, Не заїжджавші клієнти, Оборотність товарів та інші.
  • Друковані форми (UA): рахунок на оплату, видаткова накладна, накладна на повернення, прибуткова накладна, довіреність, акт звірки взаєморозрахунків.
  • Журнали документів: Дата | Номер | Клієнт | Автомобіль | Сума | Статус.
  • Фірмова тема + бічне меню (navy/gold) — вмикається у Налаштуваннях, увімкнена за замовчуванням.
  • Імпорт з Excel: майстер завантаження контрагентів для міграції зі старої облікової системи.
  • Вбудована база з ~60 логотипів автомарок, авто-призначення за назвою бренду.

Для кого

Автодилери, автосалони та СТО будь-яких марок, що переходять на Odoo і хочуть зберегти звичний документообіг.

Changelog / Що нового

19.0.1.2.0 — 2026-07-22

Added: new Service request model — scheduled date/time, customer, vehicle, reason, status; a Create Sale Order button as the entry point of the document chain. The workshop calendar is now built on requests, and the Maintenance requests menu no longer duplicates the Sale orders list.
Нова «Заявка на обслуговування»: дата/час, клієнт, авто, причина, статус. Кнопка «Створити Замовлення» — вхідна точка ланцюга. Календар СТО тепер на заявках; меню «Заявки» більше не дублює список замовлень.

19.0.1.1.3 — 2026-07-17

Changed: narrower side chatter (380px) and richer chatter logs — posted repair orders show created document names and amounts; a dedicated message on order closing.
Вужчий боковий чатер (380px) + детальніші записи в чатері: суми документів при проведенні наряду, окреме повідомлення при закритті.

19.0.1.1.2 — 2026-07-16

Fixed: an upgrade crash from versions ≤1.1.0 (introduced by the Organization feature) — the organization_id default could run before the dealer_organization table existed. Upgrades now apply cleanly.
Виправлено: збій оновлення з версій ≤1.1.0 через фічу «Організація» — тепер оновлення проходить чисто.

19.0.1.1.1 — 2026-07-15

Fixed: removed the pandas external dependency — Excel import now uses openpyxl (bundled with Odoo). The module installs cleanly everywhere, including Odoo Online / SaaS, with no manual pip install.
Виправлено: прибрано зовнішню залежність pandas — імпорт Excel тепер через openpyxl. Модуль встановлюється чисто скрізь, включно Odoo Online.

19.0.1.1.0 — 2026-07-12

Initial public release: document chain, repair orders, customer vehicles, showroom stock, parts & analogs, standard hours, reports, UA printable forms, branded theme, Excel import.
Перший публічний реліз.
